Tilli-யின் பாதுகாப்புக் கருவிப்பெட்டி!

Tilli-யின் பாதுகாப்புக் கருவிப்பெட்டியை உருவாக்க நாங்கள் தற்போது UNICEF Innovation Fund உடன் இணைந்து பணியாற்றுகிறோம். இது குழந்தைகளின் இணையப் பாதுகாப்புக்கான சமூக-உணர்ச்சிக் கற்றல் குறித்த, மூன்று பகுதிகளைக் கொண்ட, விளையாட்டு அடிப்படையிலான கற்றல் அனுபவம். பெற்றோரும் பராமரிப்பாளர்களும் தங்கள் குழந்தைகளுடன் அர்த்தமுள்ள உரையாடல்களை நடத்தவும், ஆசிரியர்கள், கல்வியாளர்கள், சமூகப் பணியாளர்கள் தங்கள் மாணவர்களுக்கு வலுவான கற்றலை வழங்கவும் உதவுவதே இந்தத் திட்டத்தின் நோக்கம்!

சேவை விதிமுறைகளுக்கான இணைப்பு: இணைப்பு

ஒவ்வொருவரும் தனித்தனியாகப் புதிதாக உருவாக்குவதை விட, இணைந்து உருவாக்கி, மக்கள் பயனடையவும் தங்களுக்கு ஏற்ப மாற்றிக்கொள்ளவும் அனுமதிப்பதில் நாங்கள் நம்பிக்கை கொண்டுள்ளதால் இந்தத் திட்டம் திறந்த மூலமாக உள்ளது. வாழ்க்கையை மாற்றக்கூடிய தலைப்புகள் பற்றிப் பெற்றோரும் ஆசிரியர்களும் மகிழ்ச்சியான உரையாடல்களை நடத்த உதவ Tilli விளையாட்டுகளையும் கதைசொல்லலையும் பயன்படுத்துகிறது.

குழந்தைகளின் சமூக நலனுக்காகச் சிறந்த உள்ளடக்கத்தை உருவாக்க, பங்களிக்க விரும்பும் எவரையும் நாங்கள் சார்ந்திருக்கிறோம். உண்மையில், இந்தத் திட்டத்தைத் தன்னார்வலர்களே முன்னெடுக்க Tilli ஊக்குவிக்கிறது! எனவே, உங்கள் சொந்தப் பயன்பாட்டுக்காக எங்கள் code-ஐ விரிவாக்க விரும்பினாலும் சரி, உதவ மட்டும் விரும்பினாலும் சரி — இந்தத் திட்டத்தைச் சிறப்பாகவும் பாதுகாப்பாகவும் ஆக்கும் எந்தப் பங்களிப்பையும் வரவேற்கிறோம்!

1. Tilli Web App

Tilli பாதுகாப்புக் கருவிப்பெட்டியில் 3 பகுதிகள் உள்ளன:

  • பகுதி 1: உணர்வுகளும் உணர்ச்சிகளும் (வெளியிடப்பட்டது)
    • உணர்ச்சிகளையும் உணர்வுகளையும் அடையாளம் காணவும், பெயரிடவும், வெளிப்படுத்தவும் கற்றுக்கொள்ளுதல்
    • பெரிய உணர்வுகளைக் கையாள ஆரோக்கியமான சமாளிப்பு உத்திகளை வளர்த்தல்
  • பகுதி 2: நம்பிக்கை (வெளியிடப்பட்டது)
    • யாரை, எதை நம்புவது என்று அறிவதே பாதுகாப்பாக இருப்பதன் அடிப்படை
    • நம்பிக்கை என்றால் என்ன, அது எப்படித் தோன்றும், எப்படி உணரப்படும் என்பதைப் புரிந்துகொள்ளுதல்
    • பாதுகாப்பான தேர்வுகளைச் செய்ய நம்பிக்கை வட்டம் போன்ற கருவிகளைப் பயிற்சி செய்தல்
  • பகுதி 3: டிஜிட்டல் பாதுகாப்பு (உருவாக்கத்தில்)
    • இணையப் பாதுகாப்பைப் புரிந்துகொண்டு, பாதுகாப்பாகப் பகிர்தல், எச்சரிக்கை அறிகுறிகளைக் கவனித்தல், அன்பாக நடந்துகொள்ளுதல், நம்பகமான பெரியவரை அணுகுதல் ஆகியவற்றில் நல்ல பழக்கங்களை வளர்த்தல்

எங்கள் 3 பகுதிகளையும் (நீங்கள் உருவாக்கும் பகுதிகளையும் கூட) எந்தவொரு மொபைல் சாதனத்திலும் இணைய உலாவி மூலம் அணுகலாம்.

வழக்கமான விளையாட்டு மென்பொருள்களைப் போலன்றி, உலாவி அடிப்படையிலான விளையாட்டுகளை உடனடியாக விளையாடலாம்; முன்கூட்டியே நிறுவ வேண்டியதில்லை!

2. Tilli IDE

IDE (Integrated Development Environment), சிறப்புத் தொழில்நுட்ப அறிவு இல்லாமலேயே Tilli Web App-இல் உள்ளடக்கத்தை உருவாக்கவும், நிர்வகிக்கவும், மாற்றவும் பயனர்களுக்கு உதவுகிறது.

எளிமையாகச் சொன்னால், எல்லா code-ஐயும் புதிதாக எழுதாமலேயே (code எழுதத் தெரியாமலேயே கூட) மேலும் பல பகுதிகளை உருவாக்க இந்தக் கருவி உதவுகிறது.

3. Tilli x Godot

எங்கள் web app-இல் உள்ள ஊடாடும் பகுதிகளை இயக்க Tilli திறந்த மூல Godot Engine-ஐப் பயன்படுத்துகிறது. ஒவ்வொரு வரி code-ஐயும் எழுத வேண்டிய அவசியமின்றி, காட்சி அடிப்படையிலான editor மூலம் செழுமையான, விளையாட்டு போன்ற கற்றல் அனுபவங்களை வடிவமைக்க Godot உதவுகிறது.

இந்த ஒருங்கிணைப்பின் மூலம், எவரும் புதிய Tilli பகுதிகளை விரைவாகவும் எளிதாகவும் உருவாக்கவும், தனிப்பயனாக்கவும், நிர்வகிக்கவும் முடியும். நீங்கள் programmer ஆக இருக்க வேண்டியதில்லை — நீங்கள் உருவாக்க விரும்பும் அனுபவத்தில் மட்டும் கவனம் செலுத்துங்கள்; பின்னணியில் உள்ள கடினமான தொழில்நுட்ப வேலைகளை Godot பார்த்துக்கொள்ளும்.
